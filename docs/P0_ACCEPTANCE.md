# P0 外部验收记录

更新时间：2026-07-15（北京时间）

本文只记录真实机构账号和真实课堂产生的证据，以及项目负责人对当前版本失败证据链要求的明确豁免。自动化契约测试、模拟响应和演示数据不能替代真实证据，豁免也不表示场景已经验证。

教师登录后进入“P0 验收”：

- 先在“设置验收范围”中选择机构本期实际采购并计划向学生开放的能力；首版必须至少包含文字和图片，视频仅在计划开放时选择。
- 学生日常文字、图片和视频分别使用对应能力的有序路由；P0 真实测试锁定教师选中的具体服务配置，不自动切换备用模型，测试前必须再次确认可能产生的费用。
- 成功与失败均保存为脱敏记录；软件真实失败自动记录标准错误码、失败来源、可用的上游 HTTP 状态码和脱敏摘要，不保存 API Key、上游响应正文、测试提示词或生成正文。
- 服务商能力矩阵分别显示软件真实调用和教师外部证据，并汇总网络、超时、限流、额度、服务不可用和内容拦截场景覆盖。
- 教师可以跳过或恢复当前版本的失败证据链要求。跳过需要明确确认和原因并进入审计日志；矩阵继续显示实际缺口，脱敏报告同时导出豁免状态。
- 真实平台失败证据可上传 PNG、JPEG、PDF、JSON 或 TXT，单文件不超过 5 MB；文本自动检查疑似密钥，图片和 PDF 必须先人工遮挡密钥、令牌及学生个人信息。
- 证据下载要求教师身份并校验 SHA-256；脱敏 JSON 报告不包含证据文件、内部路径、密钥、提示词或生成正文。
- 视频先显示处理中，只有任务成功且结果已保存到本地文件才转为通过。
- 课堂清单全部通过后才能确认真实课堂；确认与当前证据快照绑定，数据变化后自动失效。
