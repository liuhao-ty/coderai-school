面向少儿编程机构的 Windows 桌面端 AI 工具集合首版工程。

## 已实现

- React + TypeScript + Vite 前端工作台
- Zustand 统一业务状态与 HashRouter 页面路由，支持学生、教师和管理员刷新后恢复身份
- 前端按认证、学生、教师、管理员、课程、作品、工作流和批改领域模块组织，`App.tsx` 仅保留应用壳
- FastAPI + SQLite 后端服务
- 学生端：按排课学习课程、查看课堂 PPT/工程包/成果包、提交作品和查看反馈，并提供文字/图片/视频、编程助手、工作流及作品库；图片作品支持本地 Blob 和云端图片预览及原图下载
- 学龄分类：学生账号统一使用“小学低龄 / 小学高龄 / 初中高中”；小学低龄保留简化参数、卡通图片和 5 秒视频限制，其他两类开放完整创作参数，后端始终以账号学龄为准
- 教师端：查看未归档学生并执行分班、排课和密码重置；只读预览管理员发布且向本人授权的课程包和课程资料，管理本人获授权班级的提交批改、学员作品、工作流和课堂安全检测，不创建学生账号或修改课程内容
- 管理员端：拥有全机构教学管理能力；“账号管理”集中职员账号、学生开户和管理员改密，“教学管理 → 学员管理”只承担学生资料与状态维护；系统总览与教学总览分离
- 身份与内容隔离：学生只能访问本人数据；`classroom_teachers` 支持班级多教师授权，`course_package_teachers` 使用严格白名单控制教师备课与排课权限；有班级的教学数据按班级授权过滤，无班级资源按创建者过滤；管理员拥有全局访问权限
- 工作流模板：文字生成图片、创意扩写成故事、代码解释助手、项目步骤规划；文字和图片节点可行内选择具体模型，未配置模型会标灰
- 课程体系：`课程包 → 课程 → 课堂 PPT、工程包.md、成果包.md`；三个资料槽位均可为空，课程包包含至少一门课程即可发布。课程包作者必须从教师/管理员账号中选择，适用学龄使用三类多选；管理员维护课程与资料，教师按学员或授权班级排课，学生提交后解锁成果包
- 商业化基础：Ed25519 离线签名许可证、机构/席位/设备/到期校验，以及声明式签名插件协议、权限沙箱、升级和卸载
- Tauri 2 配置占位；`src-tauri/` 尚缺 `Cargo.toml` 和 Rust 入口，桌面工程与 FastAPI sidecar 托管仍待完成
- 本地数据目录：`workspace_data/`

## 本地启动

Windows 可以直接双击 `启动CoderAI学堂.cmd`，脚本会启动服务并打开浏览器。

运行维护脚本：

- `停止CoderAI学堂.cmd`：只停止 PID 与监听端口均匹配本项目的前后端进程。
- `诊断CoderAI学堂.cmd`：检查运行环境、依赖、SQLite 完整性、HTTP 服务和 PID。
- `导出CoderAI日志.cmd`：生成不包含数据库和 API 密钥的诊断日志压缩包。

也可以在 PowerShell 中运行：

```powershell
.\start-coderai.ps1
```

手动启动方式：

```powershell
npm.cmd install
python -m pip install -r requirements.txt
npm.cmd run dev
```

打开：

- 前端：http://127.0.0.1:5173
- 后端健康检查：http://127.0.0.1:8000/api/health

## 登录与身份

- 学生端：不开放自行注册。管理员在“系统管理 → 账号管理 → 学生开户”中单独创建或通过 CSV 批量创建学生，初始密码固定为 `bcm123456`；学生使用管理员分配的用户名和密码登录。
- 学生创建、资料维护和 CSV 导入使用“学龄分类”；旧“低阶 / 低龄引导”自动迁移为“小学低龄”，旧“高阶 / 高阶创作”自动迁移为“小学高龄”，不会把旧数据自动归入“初中高中”。
- 教师与管理员共用职员登录入口，系统按账号角色分别进入 `/teacher/*` 教学工作台或 `/admin/*` 管理控制台。当前本地管理员账号为 `admin / 548426`；全新数据库初始账号为 `admin / 123456`，首次登录必须设置至少 10 位且包含字母、数字和特殊字符的新密码。
- 教师和学生连续登录失败 5 次会锁定 15 分钟；两类账号的密码均使用带随机盐的 PBKDF2 强哈希保存，接口不会返回密码哈希。
- 学生会话使用持久化随机令牌；退出、停用、归档、隐私删除或密码重置会撤销旧会话。教师或管理员重置学生密码时固定恢复为 `bcm123456`，不强制首次修改。
- 教师会话：访问令牌有效 2 小时并自动刷新，刷新会话有效 7 天；可在“账号安全 → 登录设备”撤销其他设备。
- 教师新密码最低 8 位，不强制特殊符号；少于 10 位或未同时包含字母和数字时仍可使用，但每次用户名密码登录都会提示重新设置或本次忽略。管理员密码继续执行至少 10 位且包含字母、数字和特殊字符的规则。
- 管理员端“账号管理”包含“教师与管理员”“学生开户”“修改登录密码”三个页签；职员临时密码仍要求首次修改。管理员“教学管理 → 学员管理”保留学生搜索、导出、资料编辑、分班、密码重置、启停和归档恢复，不再重复提供开户入口。
- 教师端“学员管理”提供全机构学生查询、分班、批量转班和固定密码重置；“账号安全”保留教师改密，并以“登录设备”“操作审计”两个可键盘切换的子页展示账号活动。管理员“账号安全”只显示这两个活动子页。
- 工作台使用固定视口布局：左侧导航与顶部栏不随页面移动，菜单高度不足时在侧栏内部滚动，右侧内容区是唯一主滚动容器。顶部栏只显示当前身份，模型可用状态仅在“模型服务”页面显示。
- 公共隐私页展示当前政策；管理员端“隐私政策”发布全局政策并维护数据处理规则，教师的课堂安全流程执行当前政策。
- 自定义插件只接受受信任发布者签名的 ZIP 包；v1 仅解释声明式文字工具，不执行脚本，也不提供任意网络、文件、进程或环境变量权限。新课程包使用带清单、校验和及真实资料文件的 ZIP 导入导出；旧 JSON 课程接口仅保留迁移兼容并继续执行安全检查。
- “班级管理”维护班级和共同授课教师；教师可查看全部班级名称用于分班，但只能修改本人获授权班级，管理员可以管理全部班级及授课教师。
- 学生登录后只能看到自己的作品；教师只能访问获授权班级当前及历史教学数据，被移出班级授权后立即失去访问权；管理员可访问全机构数据。
- 单门课程是排课原子，整包排课会按课程顺序生成多条记录。所有课程包默认对教师隐藏，管理员在课程包详情分配可见教师后，教师才能预览并创建新排课。撤权不取消已有排课，学生继续学习和提交；教师历史记录改为只读，班级排课可由同时具备班级与课程权限的其他教师接管。
- 课程包目录位于固定左侧三级导航，通过 `/{role}/courses?package={id}` 恢复选择；右侧课程管理只显示课程概览或所选课程包详情。批改分数使用整数输入框和独立满分后缀，窄窗口自动重排。

## 课程资料与 LibreOffice

- 管理员可以在“教学管理 → 课程管理 → 课程包管理”创建课程包和课程，从启用的教师/管理员账号中选定课程包作者，并在发布前后随时补充或替换三类可选资料、维护教师可见权限。
- PPTX 由 LibreOffice 后台转换为 PDF。可通过 `CODERAI_LIBREOFFICE_PATH` 指定 `soffice.exe`；未配置或转换失败不阻止发布和排课。
- 教师和学生只能在线查看 PDF 预览，不能下载 PPTX/PDF。教师可查看并下载两类 Markdown；学生开始课程后可用工程包，首次提交后解锁成果包。
- PDF 预览通过受鉴权的中性二进制流读取，再由前端在内存中重建 PDF Blob，避免原始路径、下载 URL 或外部下载管理器接管预览。
- 课程包、原始资料和 PDF 预览位于 `workspace_data/curriculum/`，完整系统备份会一并包含。

## 桌面打包准备

当前机器还没有 Rust/Cargo，且 `src-tauri/` 目前只有配置文件，尚不是可编译的 Tauri Rust 工程。需要先补全工程骨架、确定 Python sidecar 发布方式并完成最小权限配置，之后才能运行：

```powershell
npm.cmd run tauri:dev
npm.cmd run tauri:build
```

当前项目未接入 ComfyUI 或 `comfyui-skill` 运行时，也没有增加相关依赖或配置。本轮界面整改由 React、Ant Design 和 CSS 完成；后续若接入 ComfyUI，应作为独立模型/工作流适配器实施，而不是作为界面渲染依赖。

## API 配置

进入“管理员端 → 系统管理 → 模型服务”，添加一个或多个服务配置。每个配置独立保存服务商、Base URL、API Key 以及文字、图片、视频模型；模型使用可搜索目录下拉选择，同一服务商也可以添加多次以管理不同账号或模型组合。

“能力路由”分别管理文字、图片和视频调用顺序。第一个配置为主模型，后续配置为备用模型；可使用上下按钮调整优先级。停用的配置会被跳过，认证、额度、限流、网络、超时、服务不可用或响应异常会触发备用模型切换。

工作流中的文字和图片节点直接显示模型下拉框，目录会列出系统支持的模型及配置状态。已配置且启用的模型可选；未配置、密钥不可用或已停用的模型标灰并说明原因。节点保存服务配置、服务商类型和模型标识，运行时锁定该配置；配置发生变化时返回明确错误，不会静默切换到其他模型。

当前内置预设：

- OpenAI Compatible：通用 OpenAI 兼容接口
- DeepSeek：文本、代码解释、推理任务
- MiniMax：文本、图片、视频任务提交与状态查询
- 火山引擎 / 即梦：豆包文本和 Seedream/即梦图片；Seedance 视频仅保留模型配置，暂未开放运行能力
- 通义千问 / 阿里云百炼：兼容模式文本和通义万相异步图片生成
- 智谱 GLM：文本和 CogView 图片生成

模型目录表示当前适配器明确支持的官方模型清单，不会联网自动同步厂商未来发布的全部模型。现有数据库中的非目录模型会作为兼容配置保留，避免升级丢失。当前图片专用代码覆盖 OpenAI Compatible、MiniMax、火山/即梦、通义万相和智谱，其中通义万相使用异步任务轮询；视频运行适配器当前仅有 MiniMax。

通用配置项：

- Base URL：例如 `https://api.openai.com/v1`
- API Key：使用当前 Windows 用户的 DPAPI 加密后在本机保存；备份包不包含密钥
- 文字模型：例如 `gpt-4o-mini`
- 图片模型：例如 `gpt-image-1`
- 视频模型：当前运行适配器使用 MiniMax `video-01`

未配置 API Key 时，学生端生成任务会返回明确提示，不会崩溃。

图片输出执行强制安全审核：OpenAI 兼容服务优先调用多模态审核接口，其他服务商或审核接口不可用时自动进入教师端“安全检测 → 图片复核”。图片在教师批准前不会向学生返回文件路径、显示在作品库或允许提交为作业。作品抽屉不会把云端原始 URL 作为文本显示；本地图片通过鉴权接口读取 Blob，云端图片直接预览并通过“下载原图”触发下载或跨域回退打开。

历史 P0 验收记录保留在 `docs/P0_ACCEPTANCE.md`，对应后端接口仅供管理员内部验收使用；产品控制台不显示 P0 或其他程序测试页面。

注意：当前已接入 MiniMax 文生视频任务提交与查询。图生视频参考图片可通过学生端上传，后端会在大小和类型校验后转换为受限 Data URL 提交；不接受手工填写任意本地文件路径。

## 自动化测试

后端冒烟测试使用独立临时数据库和临时文件，不会修改 `workspace_data/coderai.db`：

```powershell
npm.cmd test
```

完整检查（后端测试 + 前端生产构建）：

```powershell
npm.cmd run check
```

Chrome 端到端课堂闭环测试使用独立临时数据库，不会修改正式课堂数据：

```powershell
npm.cmd run test:e2e
```

真实 PPTX 转换测试会使用独立数据目录，通过课程 API 上传 PPTX，验证 LibreOffice 生成有效 PDF、教师可预览且不能下载原件：

```powershell
npm.cmd run test:ppt-conversion
```

端到端门禁同时覆盖键盘导航、axe 严重级别可访问性扫描、`900x800`、`1280x720`、`1920x1080` 和高 DPI Windows 显示检查，并检查左侧课程目录、深链接恢复、教师授权、批改分数布局、资料卡、排课表和 PDF 抽屉。

全量门禁（后端测试 + 生产构建 + 端到端测试）：

```powershell
npm.cmd run check:full
```
